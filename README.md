# Descarga para Windows (paquete completo)

Rama solo para descarga: **Code → Download ZIP** (arriba a la derecha en GitHub).

1. Descomprima el ZIP en una ruta corta, por ejemplo `C:\Enrolamiento\`.
2. Doble clic en `1-ejecutable-windows\iniciar-local.cmd`. No requiere instalar nada.
3. Se abre http://localhost:5180 con envío **simulado** (no manda correos).

Contenido: `1-ejecutable-windows` (app con .NET incluido), `2-codigo-fuente` (código, `node_modules` para Windows y `paquetes-nuget` para compilar sin internet). Instrucciones completas en `LEEME.md`.

El código fuente vigente está en la rama `claude/pensive-ptolemy-7d2nje`.
